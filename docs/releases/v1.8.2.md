提供 Linux 和 macOS 体验包；Windows 用户可继续使用 [v1.8.1](https://github.com/cj-lyons/shixu/releases/tag/v1.8.1)。

## 如何选择

| 系统 | 下载文件 |
| --- | --- |
| Ubuntu / Debian x64 | `Shixu-1.8.2-linux-amd64.deb` |
| 其他 Linux x64 | `Shixu-1.8.2-linux-x86_64.AppImage`（需要系统支持 FUSE） |
| 苹果芯片 Mac（M 系列） | `Shixu-1.8.2-mac-arm64.dmg` 或同架构 ZIP |
| Intel Mac | `Shixu-1.8.2-mac-x64.dmg` 或同架构 ZIP |

macOS 将应用拖入 Applications；Linux AppImage 需授予执行权限。SHA256SUMS.txt 提供校验值。

## 验证范围

各包由对应系统与架构的 GitHub 构建机生成，通过代码检查、模拟 WebDAV 测试、包内容检查，以及已打包应用的启动、任务保存、计时开始/暂停、花卉切换、完整退出再启动的数据保留检查，全部通过后才发布。

Linux 图形测试使用 Xvfb，且测试进程临时使用 `--no-sandbox` 以适配托管 CI 环境；此参数不写入安装包或正常启动器。CI 测试不代表已验证用户桌面的沙箱、托盘、系统通知或所有发行版兼容性。真实坚果云同步和声音播放需要用户实机继续验证。

## 已知限制

- Mac 包没有 Developer ID 签名或 Apple 公证，不能等同于 App Store 或已公证发行版；系统可能阻止打开。仅在确认来源和校验值后按系统官方流程处理，不要关闭系统整体安全保护。
- Linux WebDAV 保存应用密码需要系统密钥环；不使用 basic_text 后端保存凭据。没有可用密钥环时仍可本机管理任务。
- Linux 托盘和通知取决于桌面环境；托盘初始化失败时关闭窗口会退出，避免窗口隐藏后无法再打开。
- 包中不带个人数据、账号凭据或任何歌曲。音乐可自行导入或选择本机文件夹。
- 版权署名已统一为 CheJ，MIT 代码许可与素材授权范围保持不变。原有 Windows v1.8.1 发行包保留。
