# 拾序 v1.12.0 · 一键专注、项目跟进与自定义提醒

本版汇总近期开发版的功能与修复，提供 Windows x64、Linux x64、macOS arm64/x64 桌面安装包。公开安装包不含歌曲、个人任务或同步凭据。

## 更新内容

- **一键专注**：任务卡片点“专注”直接开始倒计时；同一任务暂停后可继续，重复点击不重置，其他任务不能覆盖当前计时。
- **四段进度**：显示当前专注段、累计推进与长休息建议；暂存记录保存后不重复计数。
- **项目跟进**：长任务可选“作为项目跟进”，添加下一步、完成当前步或调整；负责人和跟进时间选填，保留步骤历史。只提醒当前步骤。
- **自定义提醒**：填写内容、选择时间及重复方式；支持一次性、每天、工作日、每周，30分钟后/1小时后快捷时间。到点用花语卡片提示，可已处理或稍后10分钟。
- **提醒恢复**：错过的自定义提醒保留为待确认，不连续补弹；一次性处理后收起，重复提醒确认后安排下一次。
- **完成排序**：按实际完成时间从新到旧排列；修改文字不改变排序，重新打开后再次完成记录新时间。历史无完成时间的任务不补造日期。
- **图标修复**：修正开发版托盘图标错误目录；玉兰白开发图标与日常版粉色图标分别保留。

- **运行组件维护**：更新 Electron 44.10.2、Vite 8.3.6、Zod 4.6.7，并验证原数据格式与迁移行为。

## 更新前请读

从托盘完全退出旧版，使用“数据 → 备份数据”保留备份后再更新。两台同步电脑请同时升级本版。

本版任务与云端格式升为 **4**，首次迁移保留旧库备份。旧 v1.11.0 客户端不能直接打开或覆盖新版数据；保留旧安装包不代表可以直接降级读取新版库。

项目步骤、完成时间和已保存的专注记录参与任务同步。自定义提醒独立保存于本机用户目录的 `custom-reminders.json`，**暂不参与坚果云同步，也不包含在任务数据库备份中**。退出软件后可单独复制该文件备份。

工作日指周一至周五，不自动识别节假日调休。重复提醒需确认当前这次后才安排下一次；错过多次合并为待确认。电脑关机、休眠或软件完全退出时无法弹窗。自定义提醒不提供持续闹铃。

## 下载与验证

- Windows x64：`Shixu-1.12.0-x64-Setup.exe`、`Shixu-1.12.0-x64-Portable.exe`
- macOS arm64 / x64：各自的 DMG、ZIP
- Linux x64：deb、AppImage
- `SHA256SUMS.txt`：所有安装包校验值

发布流程要求各平台代码检查、提醒/同步/项目/排序/进度测试、安装包内容检查与打包应用实际启动通过后才上传。Windows 新功能另用独立示例数据验证，未操作日常任务库。真实坚果云跨设备、用户桌面的通知权限和电源管理仍需试用反馈。

安装包未提供开发者证书签名，Mac 未 Apple 公证，也不是 Mac App Store 版本。系统安全提示不代表已完成签名认证。
