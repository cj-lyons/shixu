# 拾序 v1.11.0 · 未来待办与花语休息提醒

提供 Windows x64、Linux x64、macOS 苹果芯片 arm64 与 Intel x64 体验包。所有公开包均从不含本机资料的源码构建，不附带任何歌曲、个人任务或同步凭据。

## 本次更新

- **未来待办**：在首页“安排以后”记录未来事项，支持提醒时间与截止前提醒；到了计划日期自动出现在今日安排及原清单，不重复创建任务。同一时刻的提醒合并显示。
- **录入更顺手**：日期选择支持确定，保存栏固定在弹窗底部，支持 Ctrl / ⌘ + Enter 保存。
- **活动与喝水提醒**：分别开关、设置间隔与每日时段，支持完成重算和稍后10分钟。
- **自然休息判断**：可关闭的电脑空闲检测。键鼠空闲5分钟暂停活动提醒，恢复操作后重新计时；不推断已起身，喝水提醒不受影响。
- **会议暂停**：首页或托盘一键暂停活动/喝水30分钟或1小时，可提前恢复。结束后重算间隔；任务截止和番茄钟继续运行。
- **花语小卡片**：沿用当前花卉主题，在屏幕角落轻量显示，提供完成、稍后10分钟和关闭；也可关闭小卡片，继续使用系统通知。

## 更新与数据

先从托盘完全退出旧版，再安装或启动新版。更新前建议使用“数据 → 备份数据”。

沿用任务与同步格式3；从旧版首次升级时会自动迁移任务库并保留迁移前备份。两台同步电脑建议一起升级，避免旧客户端覆盖新字段。活动/喝水选项仅保存在本机，不参与 WebDAV 同步。

公开包不包含音乐，可自行连接本机曲库；私人古琴内部测试包不属于本次公开发行。

## 验证范围与限制

- 发布流程在各自系统与架构的构建机执行类型检查、平台检查、未来待办与办公提醒测试、模拟 WebDAV 同步测试和包内容检查，通过已打包应用的启动、任务保存、番茄钟开始/暂停、花卉切换及重启保留测试后才发布。
- 花语小卡片在构建机支持通知时进行界面验证；不支持时报告跳过，不以此宣称系统通知已送达。Windows 本地已独立验证隐藏窗口下的卡片、动作与原生通知回退。
- 5/30/60分钟到点、自然休息和恢复逻辑使用模拟时钟验证；没有检测真实坐姿或饮水行为。真实坚果云与用户桌面上的通知、托盘、空闲检测仍需实机使用反馈。
- Linux 图形测试使用 Xvfb，测试进程的 `--no-sandbox` 仅用于临时 CI 构建机，不写入正式启动器。Linux WebDAV 凭据保存需要系统密钥环。
- 当前安装包没有开发者证书签名；Mac 未 Apple 公证，也不是 Mac App Store 包。系统可能提示来源未经验证，请核对来源与校验值。
