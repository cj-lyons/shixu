# 拾序 1.9.2 · Windows 更新包

2026-10-26。汇总 1.9.0 / 1.9.1 开发版及首页视觉调整，提供 Windows x64 安装版与免安装 EXE。本次为本机打包，没有自动发布到 GitHub，也未生成新版 Mac / Linux 安装包。

## 本次更新

- 未来事项提醒、同一轮多事项合并通知、重启和休眠恢复后补查。
- 首页“安排以后”；未到安排日的事项暂存，到当天自动显示在今日安排和原清单。
- 截止与提醒日期支持确定、双击，提供截止前 1 小时 / 1 天提醒。
- 保存栏固定，支持 Ctrl / ⌘ + Enter，保留必填校验。
- 首页手账式标题、轻量入口和随主题变化的配色。

## 安装与升级

1. 在旧版的“数据”菜单或偏好设置中导出备份；从托盘选择“退出拾序”，避免只关闭窗口。
2. 日常使用选择 `Shixu-1.9.2-x64-Setup.exe`。免安装体验选择 `Shixu-1.9.2-x64-Portable.exe`。
3. 桌面正式版继续使用原有 ShixuDesktop 用户数据目录，不会导入开发版 ShixuDevelopment 的独立数据。安装包不包含用户数据库、账号、WebDAV 应用密码或私人音频。
4. 从 1.8.x 升级时，本机格式升级至 3 前会创建一致性备份；两台用于 WebDAV 同步的客户端都需升级至 1.9.x。1.9.0 / 1.9.1 用户沿用格式 3。
5. 不要直接用旧程序写新版数据；回退时完全退出软件、保留现状，并使用升级前备份和独立数据目录。

## 使用范围

- 桌面通知要求拾序运行且系统允许通知；收进托盘仍可提醒，完全退出、关机或休眠期间无法准时弹窗，恢复运行后补查。
- 安装包不附带个人歌曲；在播放器中选择自己的音乐文件夹。
- 当前 Windows 包没有配置发布者代码签名；是否接受运行由用户根据下载来源自行决定。
- 验证记录随本机输出交付；独立测试不等于真实坚果云、两台物理电脑或所有 Windows 设备验收。
