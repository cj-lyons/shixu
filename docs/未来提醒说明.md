# 未来提醒 · 1.9.1 开发版

2026-10-26 更新。1.9.0 加入一次性的未来待办提醒，1.9.1 完善首页入口、日期确定、快捷保存和当天归入清单的流程；保持原有任务分类，没有增加重复规则或复杂项目管理。

## 如何使用

1. 首页“今日安排”的“记一件事”旁增加“安排以后”。前者可以录入普通事项，也可以填写提醒；后者预填下周一 09:00，日期可自行修改。无需先进入“未来提醒”。
2. 单击日期后点“确定”，或双击日期直接确定；选择日期会预览到当前表单，点击选择器的“取消”恢复原值。日期确定不等于保存整条事项。
3. 录入框底部的“保存事项”始终可见；Windows / Linux 按 Ctrl + Enter，Mac 按 ⌘ + Enter 可保存，标题和其他必填项仍正常校验。
4. 在左侧“未来提醒”查看尚未到安排日的事项，按提醒时间排序；首页会显示未来事项数量和查看入口。

“下周一”严格指下一个星期一：例如 2026-10-26（星期一）点击，会选择 2026-11-02 09:00；可在选择器改成今天或其他日期。

三件待办分别设置相同时间即可，同一轮到时的事项合并成一条系统通知，并列出前三件事项。提醒时间不等于截止时间：可以周一提醒开始处理、周五才截止。填好截止时间后可选“截止前1小时”或“截止前1天”；若提前时刻已经过去，该快捷项不可用。只填截止时间仍然仅在到期时提醒，不会默认提前弹窗。

## 当天自动进入清单

- 未到提醒日期：放在未来提醒，暂不出现在原清单。
- 到提醒日期：当天早上打开软件就会出现在“今日安排”和原清单，无需等到提醒钟点。普通事项出现在“临时收件箱”，集中处理事项回到“集中处理”，交接事项仍在“交接与等待”，保留负责人和责任边界。
- 到所选钟点：发送系统通知；若截止时间更早，会优先将已截止的事项显示出来，避免被未来日期隐藏。
- 当天没有完成：继续留在今日安排和原清单，不会消失；取消提醒则立即回到原清单。
- 这是同一条事项在不同日期的自动展示，不会复制记录、改写分类或因两台电脑启动先后生成重复事项。跨日保持软件开启也会自动刷新展示。

编辑时可以修改时间或取消提醒。完成或删除事项后不再发送尚未触发的提醒；已经送达系统通知中心的旧通知不会因此撤回。已经提醒的事项仍保留在今日安排和原清单中，直到完成或取消提醒，避免遗漏。

## 通知范围

- 桌面版：需允许系统通知，并让拾序运行；关闭窗口收进托盘可以继续提醒。
- 完全退出软件、关机或休眠时无法准时弹出；再次启动或恢复运行后会补发未完成且错过的事项提醒。
- 每台电脑分别保存提醒送达记录，所以两台都运行时可能各提醒一次。Windows 勿扰、通知权限等系统设置会影响实际展示。
- 网页版需保持网页打开；补查和去重保存在当前浏览器，清除浏览器数据后可能再次提醒。
- 按所选本地时间保存为带时区的绝对时刻；另一台电脑显示为自己的当地时间。

## 版本与数据

- 本机数据格式由 2 升至 3，服务器第一次升级时先创建 SQLite 一致性备份，位置在数据目录下 `schema-backups/before-format-3-*.sqlite`。
- WebDAV 快照格式升至 3，新版可读取旧格式 1 / 2；旧版不支持新快照。两台电脑需都升级后再使用同步。
- 没有修改坚果云凭据、同步目录或自动同步间隔。
- 1.9.1 沿用 1.9.0 的格式 3，不增加新的数据库字段。该轮修改前另存本地版本标记 `before-reminder-flow-1.9.0`。
- 旧源码保留在 Git 提交历史，本轮开始前的本地版本标记为 `before-future-reminders-1.8.2`。既有安装版和 GitHub 安装包没有覆盖。
- 如需退回旧程序，使用升级前的备份并保持独立数据目录，避免拿旧版直接写新版数据；涉及真实数据恢复时先完全退出软件、另存现状。
