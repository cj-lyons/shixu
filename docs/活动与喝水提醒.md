# 小小提醒：起身活动与喝水 · 1.11.0

## 1.11.0 新增

1. **自然休息判断**：在“提醒时段与测试”中可关闭“电脑空闲5分钟，暂停活动提醒”。默认启用；仅查询操作系统的空闲秒数，不记录按键或鼠标内容。空闲满5分钟后暂停活动提醒，恢复操作时从完整间隔重新开始，喝水间隔不受影响。空闲只说明没有操作电脑，不能证明已起身。系统无法读取空闲时间时，退回普通定时提醒。
2. **会议暂停**：首页“小小提醒”下或托盘“活动与喝水”中，选择暂停30分钟/1小时，可提前恢复。两项办公提醒暂停，任务、截止与番茄钟继续运行。暂停到期后重新计时，不立即补弹；暂停结束时间保存在本机，重启会继续尚未结束的暂停。
3. **花语小卡片**：活动/喝水到点时，在鼠标所在屏幕右下角显示当前花卉主题的小卡片，主窗口收进托盘也能使用。卡片不会主动抢焦点，约1分钟自动关闭；“关闭”仅收起本次提示，不关闭后续提醒。“稍后10分钟”推迟本次涉及的提醒；完成按钮只重置本次涉及的项目。合并卡片明确写“已活动，也喝了水”，分别到点时显示“我已活动”或“我已喝水”。

关闭“花语提醒小卡片”后仍使用系统通知。锁屏和休眠会收起卡片；锁屏时不弹活动/喝水提醒。会议暂停会收起已有卡片。当前花色以卡片出现时的工作台主题为准。

新功能独立编写，参考了 [Stretchly](https://github.com/hovancik/stretchly) 的自然休息思路，没有复制第三方源码。操作系统空闲时间接口见 [Electron 官方文档](https://www.electronjs.org/docs/latest/api/power-monitor#powermonitorgetsystemidletime)。

### 新版验证

- 独立时钟测试：空闲只暂停活动、恢复重算、关闭后普通定时、会议暂停/提前恢复/到期、重启保留、旧配置兼容、读取空闲失败退回定时。
- 集成调度：会议期间番茄结束及任务到期通知仍发出。
- Windows Electron 独立测试资料：真实面板操作、樱花与郁金香卡片、隐藏工作台不抢焦点、稍后10分钟、完成重算、会议关闭卡片、禁用卡片后原生通知 shown 事件。
- 未运行整段真实5/30/60分钟等待，相关到点分支使用可控时钟测试；未在 macOS/Linux 桌面实测。未修改真实任务、同步账号或数据库。

## 1.10.0 原有功能

首页右侧“小小提醒”改为两个独立的办公提醒，集中处理时间仍在偏好设置中，原有任务到期与集中处理通知继续保留。

- 初次默认关闭，按需开启。起身活动默认每 60 分钟，喝水默认每 45 分钟，可选 15 / 30 / 45 / 60 / 90 / 120 分钟。
- “我已活动”“我已喝水”重新计算对应间隔，不影响另一个提醒；“稍后10分钟”只推迟对应一项。
- 点击“提醒时段与测试”可限制提醒时间，默认每天 09:00—18:00，支持修改或关闭时段限制；结束时间须晚于开始时间。
- 同时到时合并通知；番茄休息阶段不弹出活动/喝水提醒，专注快结束时让位于计时提醒，其他软件通知刚发送后也会暂缓。
- 完全退出后重新打开、长时间未运行或系统休眠恢复时重新计算间隔，不把离开期间的提醒逐条补发。配置保存在对应客户端用户目录的 `wellbeing.json`，不进入 WebDAV 任务同步。
- 收进托盘仍能提醒，完全退出、关机或休眠期间无法提醒；需系统允许通知。当前是桌面功能，网页显示桌面版提示，不宣称网页关闭后可提醒。

这是按时间间隔提供的温和提示，不检测实际坐姿或饮水量；可按自己的工作节奏调整或关闭。

## 验证

独立时钟测试覆盖开关、合并、重置、推迟、休息、通知让位、时段和重启；独立 Windows Electron 测试通过真实面板操作、配置持久保存及隐藏窗口时原生测试通知的 `shown` 事件。间隔到点逻辑用模拟时钟验证，没有等待一整个真实办公时段，也未验证其他操作系统桌面。

本轮沿用任务数据格式 3，不修改真实任务、坚果云配置或旧安装包；本地 Git 历史保留旧版。
