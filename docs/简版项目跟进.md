# 简版项目跟进 · 1.12.0

## 使用方法

1. 新建或编辑原有任务，勾选“作为项目跟进”，保存。
2. 在任务卡展开“项目跟进”，点击“＋下一步”，填写一句要做的事。负责人和跟进时间选填，支持Ctrl/⌘+Enter保存。
3. 可以先只加当前一步，也可以按顺序添加后续几步。例如：整理方案 → 等袁部确认方向 → 选择老师 → 确认课程安排。
4. “完成这一步”保存完成时间和记录，把下一步变为当前步骤。它不会完成整个项目。所有步骤完成后，可以继续添加下一步，也可以勾选任务前的圆圈，明确结束整个项目。
5. “需要调整”默认编辑当前步骤，也可选择后续未完成步骤，修改内容、负责人、跟进时间，并选填一句备注。历史记录保留原来的标题与当时资料，不改写已完成步骤。

完成整个项目后移到“已完成”；重新打开后原步骤及记录仍在，可以添加后续步骤。第一版最多60步、300条推进记录，达到上限时提示另建后续项目，不自动丢弃旧记录。

## 简洁与提醒

普通任务不会出现步骤面板。关闭“作为项目跟进”只收起功能，不删除已有内容，再开启就能继续使用。没有增加单独项目页面、连线编辑器、甘特图或新的分类体系。

每步的负责人不等于项目交办人，也不会自动改变任务原有清单。跟进时间仅作用于当前步骤：当天显示在今日安排，到了时刻由桌面软件提醒；未开始的后续步骤不提醒，变成当前步骤后若已到时则补查。留空则不提醒。项目已完成或关闭项目模式时停止步骤提醒，原任务独立设置的提醒和截止时间保持原规则。

“交接与等待”原有的“下次何时跟进（暂不提醒）”仍是旧的备注字段。项目步骤里新选的“这一步的跟进时间”才会发送本版新增的项目提醒。

## 保存、升级与同步

步骤与记录随任务保存进SQLite，可通过原WebDAV机制同步。并发编辑同一项目会保留两个版本，明确选择后再收敛，不擅自猜测两份意见的先后关系。保存失败保留输入供重试；编辑期间发现另一处已更新时禁止直接覆盖，需核对最新步骤后重新编辑。

本版数据格式和云端同步格式为4，兼容读取旧格式1/2/3。首次启动旧任务库会在该客户端数据目录的`schema-backups`中生成`before-format-4-*.sqlite`迁移前备份。升级前仍建议自行通过“数据 → 备份数据”另存一份。

两台参与同步的电脑都需升级1.12.0。旧1.11.0不能直接打开新版数据库或读取格式4同步文件；旧程序和旧安装包保留，但不能混用新版数据。如果要退回旧版，应另存好新版数据，使用独立目录恢复迁移前备份，不覆盖当前数据。

## 本轮验证与交付

- 独立时钟测试验证步骤顺序、完成项目保护、历史快照、跟进提醒去重与调度重启。
- 独立格式3数据库迁移验证任务原样保留、迁移前备份生成、格式3写入拒绝。
- 两个独立SQLite和模拟WebDAV端验证步骤与历史往返、并发反馈保留两版、明确选择后收敛。没有使用真实账号或密码。
- Windows Electron实际界面验证步骤录入、当前步完成、调整备注/日期、模式开关保留、完整重启、并发修改保护、网络失败后重试、Ctrl+Enter、较小窗口、项目结束与重新打开。

本轮源码与开发版在本机更新，不自动发布GitHub。内部音乐测试包沿用原私人曲库和独立数据目录，仅供本机使用；以前版本的EXE保留。
