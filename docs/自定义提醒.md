# 自定义提醒 · 开发版

在首页右侧“小小提醒”的“自定义提醒”中点“添加”，填写提醒内容、时间和重复方式，即可保存。可用“30分钟后”“1小时后”快捷时间，也可通过日期选择器确定具体时间。Ctrl+Enter 可快速保存。

支持不重复、每天、工作日、每周。工作日指周一至周五，不自动识别节假日调休；每周以首次选择的星期和本地时间为准。可以编辑、暂停、恢复和删除提醒。

## 到点如何处理

- 到点显示跟随当前花卉主题的小卡片，不主动抢走正在使用的窗口焦点。
- “已处理”：一次性提醒收进“已处理”；重复提醒安排下一次。
- “稍后10分钟”：保存新的提示时间，不改变重复提醒原定的每日/每周时间。
- 关闭小卡片或自动收起不会当作已处理，首页仍保留“待确认”。
- 同时到期的提醒不连续弹窗：卡片展示其中一条，并告知其他条数；其余在首页逐条确认。

## 重启与运行范围

关闭主窗口收进托盘仍会提醒。完全退出软件、电脑关机或休眠期间不能弹窗；再次打开/恢复时将错过的内容记为“待确认”，不连续补弹。每天/每周的提醒需要确认当前这次，才安排下一次；错过多次合并为一次待确认。

自定义提醒独立于工作任务，不受活动/喝水的会议暂停、专注休息抑制影响；仍遵守全局软件提醒开关，锁屏时不弹卡片。关闭全局软件通知期间到期的提醒也会保留在首页。

第一版仅保存在本设备用户目录的 `custom-reminders.json`，不参与坚果云同步，也不包含在任务数据库备份中。退出软件后可单独复制该文件作为提醒备份。没有改动任务数据格式。

本次只参考 RemindOn 的提醒交互及 TrayTodo 的快捷时间设计，使用拾序自己的调度与花卉组件实现，未引入对方代码或素材。
