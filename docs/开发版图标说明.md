# 拾序开发版 · 玉兰白图标

开发版使用独立的玉兰白图标。资源为本项目的矢量绘制，源文件`desktop/dev-magnolia.svg`，对应PNG和含16/20/24/32/40/48/64/128/256像素尺寸的ICO；`dev-icon.ico`保留为相同图标，兼容原有引用。正式版`icon.ico`和`icon.png`不变。

`desktop/build.mjs --dev`会把玉兰ICO/PNG复制到开发版目录。桌面“拾序·开发版”快捷方式仍调用原来的隐藏启动脚本，图标改指向`desktop/dev-magnolia.ico`。

Windows开发启动器调用`prepare-development-runtime.mjs`，在忽略版本控制的`desktop/dev-runtime/<Electron版本>/`准备独立运行环境，复制并设置开发程序图标及名称。共享`node_modules/electron/dist/electron.exe`不被改写；图标内容改变时使用新的程序文件名，避免沿用旧程序图标缓存。文件编辑工具沿用项目锁文件中已有的`electron-winstaller/vendor/rcedit.exe`。

以后仍双击桌面的“拾序·开发版”即可。图标更换需要完全退出当前开发版后重新启动，Ctrl+R只能刷新页面。当前修改不要求删除系统图标缓存或重启资源管理器。

本机独立测试资料验证了新程序启动、开发版身份、窗口大小图标槽位/类图标、原生提取的程序图标以及资源文件一致性。没有停止正在使用的工作台或更改任务、计时与同步资料。
